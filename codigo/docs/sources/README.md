# Fuentes de la muestra

Consulta: 14/11/2026. Los HTML son copias públicas para trazabilidad interna. No se sirven en la compilación `dist/` ni son necesarios en el navegador del visitante.

- `home.html`: portada oficial y recursos de identidad.
- `calzado.html`, `disenador.html`, `arabes.html`: listados descargados directamente.
- `carrito.html`: carrito público vacío, sin enviar pedidos.
- `product-<id>.html`: diez fichas con datos estructurados de producto.
- `manifest.json`: URL de cada ficha y fotografía y fecha de consulta.
- `original.css`: estilos públicos usados para observar la paleta del sitio existente.

`/contactus` devolvió 404, por lo que no se archivó como una página de contacto válida. Instagram y Facebook no fueron accesibles para inspección. No se accedió a cuentas privadas ni al panel de administración.

Las fotografías, el logo y los nombres pertenecen a sus respectivos titulares. Se incluyen como material público de referencia en una propuesta local para el negocio. No se ha confirmado licencia para una publicación comercial. No atribuir a Aleph Zero una aprobación de esta propuesta.
